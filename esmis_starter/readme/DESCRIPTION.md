Entry point for installing eSMIS — a Student Management Information
System for Philippine higher education institutions (HEIs).

Installing this module pulls in all eSMIS foundation modules and
configures the database with Philippine localization defaults
(PHP currency, PH country, Asia/Manila timezone).

### What Gets Installed

- **esmis_base** — Common infrastructure and configuration menu
- **esmis_vocabulary** — Configurable code lists
- **esmis_security** — Security groups and infrastructure mixins
- **esmis_consent** — RA 10173 consent management
- **esmis_approval** — Approval workflows

### Localization Defaults

- Currency: Philippine Peso (PHP)
- Country: Philippines (PH)
- Timezone: Asia/Manila
